# Dark ASCII redesign — design

Mockup: `docs/design/mockup-ascii.html` (home and the TASSOS result).

## Why

The site read as a dark newspaper (big grotesk headlines, serif body, editorial cards). Its readers are busy journalists and researchers. The redesign makes the site plain and fast to act on:

- the action first: the search box is the first thing on the home page
- the answer first: a result opens with one verdict line ("Listed by 3 of 4: US, EU, UK")
- state always visible: when the lists were last updated
- short lists, one next step

## Visual system

- **Dark paper, one font.** JetBrains Mono for everything (400 / 500 / 700). Schibsted Grotesk and Source Serif 4 are dropped from every page.
- **Colour.** Paper `oklch(15% 0.008 250)`, ink `oklch(93% 0.008 95)`, muted and faint greys, one signal red `oklch(70% 0.18 32)` for "listed", focus and the one primary action. Green only for "fresh" and new changes (already used).
- **ASCII as structure.** Square corners, hairline rules, `[ label ]` buttons, `├─ └─` trees, dotted leaders, `──▸` arrows, `■ □` list markers. No shadows on page sections.
- **One live picture.** The home page draws an ASCII tanker above the waterline and a moving current below it (`app/sea.js`). Static under reduced motion. Decorative (`aria-hidden`).
- **Measure.** Text blocks stay near 80 characters.

## Pages

All 23 pages load `app/style.css`, so the system lands there. Page-specific inline styles already use its tokens.

| Page type | Files | Change |
|---|---|---|
| Home and results | `index.html`, `app/render.js` | Home: status line, ASCII field, action headline, search, examples; research as a dotted-leader list. Result: verdict line under the name. |
| Research notes | 13 pages generated by `scripts/build_docs.py` | Template: new font link and footer; regenerate. |
| Hand-made pages | how-sanctions-work, about-the-data, updates, chips viz (4) | Font link and footer only; the rest follows the tokens. |
| Graph pages | shadow-fleet map, influence network, clean-names graph | Font link and footer only; canvas colours read the tokens. |

## Constraints

- Keep every id, class, `data-*` hook and button name the tests and scripts use.
- No new dependencies. No build step.
- Footer drops "team": "Research snapshot: VeilTrace, Trace the Unseen, 25 Sep 2026".
- Mobile: no horizontal scroll at 320 px.

## Done when

- `npm test`, the Python tests and `npm run smoke` pass.
- Screenshots at 1280 and 375 px for home, a result, a research note, a chips chart, the map and the network look like the mockup's system.
